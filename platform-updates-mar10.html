Profile-Level Calendar Link Auto-Selection
Campaign Creation • Backend API

When creating a campaign and selecting a "Send From" email, the system now automatically populates that sender's Calendly link and phone number from their user profile. This ensures every campaign uses the correct sender's scheduling link instead of requiring manual entry.

  • The /api/sender-emails endpoint now returns phone and calendlyLink for each sender
  • Campaign creation modal auto-fills Calendly and phone fields on sender selection
  • The campaign executor already resolves the sender's calendar link at send time via senderUser.calendlyLink

Enhanced Apollo CSV Contact Import Mapping
Contact Import • Column Auto-Detection

CSV imports from Apollo now automatically detect and correctly map more fields. Previously, fields like Corporate Phone, Company, and LinkedIn URL were missed during import, causing blank data in campaign contacts.

  • Phone: Now prioritizes "Corporate Phone" and "Work Direct Phone" (Apollo's default export fields) ahead of generic "Phone"

  • LinkedIn: Added "Person Linkedin Url" (Apollo's exact header)
  • Title / Job Title: New mappable field with auto-detection for "Title", "Job Title", "Position", "Role", "Designation"
  • City / State: Added "Person City", "Person State", "Location City/State" patterns
  • Preview table in mapping modal updated with Title and LinkedIn columns

Two-Variant Email Signature System
Email Queue • Spam Prevention • Branding

Outbound campaign emails now include a professional, branded signature that adapts based on position in the sequence. First-touch emails use a minimal signature to reduce spam risk, while follow-up emails include the full branded Paycile HTML signature.

  • Built buildEmailSignature() with two variants: 'minimal' and 'full'
  • Email queue processor auto-detects first-touch vs. follow-up by checking prior sent emails to the same contact
  • Full signature includes Paycile logo, sender contact info, Calendly scheduling link, LinkedIn, and website
  • Every email includes a visible unsubscribe link and company address in a clean footer
