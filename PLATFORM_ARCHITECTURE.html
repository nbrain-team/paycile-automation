1. Executive System Overview

Paycile Automation is a production-grade, AI-powered multi-channel marketing automation platform purpose-built for B2B outreach campaigns. The system enables Business Development Representatives (BDRs) to design, personalize, and execute outreach sequences spanning Email, SMS, Voicemail Drop, and LinkedIn — orchestrated through an intelligent visual funnel builder with AI-generated content and human review gates at every critical juncture.

The platform is deployed on Render with a PostgreSQL database, Node.js/Express API server, and a React single-page application frontend. AI capabilities are powered by OpenAI GPT-4 for campaign generation and inbox intelligence, with GPT-4o-mini optimized for high-throughput email personalization.

Core Design Principles

  • Human-in-the-Loop: Every AI-generated piece of content passes through BDR review before delivery. Automation can be paused and resumed per-contact at any stage.
  • Multi-Channel Orchestration: Campaigns coordinate email, SMS, voicemail, and LinkedIn messaging through a unified visual graph of workflow nodes and timed edges.
  • AI-Augmented, Not AI-Replaced: AI generates drafts, variations, and personalization — humans approve, edit, and own the final output.
  • Throttled & Compliant Delivery: Email sending uses queue-based throttling (1–2.5 minute randomized delays) with SMTP rotation to maintain deliverability and CAN-SPAM compliance.
  • Template-Driven Architecture: Funnel templates with versioning allow rapid campaign launch while preserving institutional knowledge and proven sequences.
  • CRM Integration First: HubSpot and Apollo.io integrations ensure lead data flows bidirectionally between outreach and pipeline management.

2. System Architecture

The platform is organized into four primary layers, each with distinct responsibilities and clear interfaces between them.

Layer 1 — Data Ingestion & Storage
CSV Contact Import → Apollo.io Enrichment → PostgreSQL (Prisma) → Contact Records
HubSpot CRM Sync → Lead Submission API → CRM Pipeline
Template Library → Template Versioning → Campaign Graph (Nodes + Edges)

15 PostgreSQL tables managed via Prisma ORM • Bulk import with rawJson preservation • Template CSV import/export

▼
Layer 2 — AI Processing & Orchestration
AI Campaign Builder GPT-4 Turbo — Natural language → full funnel generation
AI Email Personalizer GPT-4o-mini — 1-to-1 contact-aware email personalization
Inbox AI Generator GPT-4 Turbo — BDR response drafts with intent detection
Campaign Executor → Node Router → Merge Tag Engine → Channel Dispatcher

Node types: email_send, sms_send, voicemail_drop, linkedin_message, wait, decision, stage, task, start

▼
Layer 3 — Multi-Channel Output & Delivery
Email Queue → Microsoft Graph API → SMTP Rotation (Fallback)
SMS Dispatcher → Twilio / Bonzo
Voicemail Engine → ElevenLabs TTS → DropCowboy Delivery

Queue worker runs every 30s • 1–2.5 min randomized email delays • SMTP rotation for volume • Unsubscribe compliance

Automation Check-Out → ⚠ Manual Intervention → Check-In / Resume

7. Human Review Workflow

Human oversight is embedded at every critical decision point. The system provides three distinct review workflows:

7a. AI Content Review Flow

AI Generates Content → Content Saved as Draft → ⚠ BDR Reviews → Approve / Edit / Reject → Execute Campaign

7b. Personalized Email Approval Flow

Trigger Personalization → GPT-4o-mini Personalizes → Per-Contact Drafts Created
▼
⚠ BDR Reviews Each Email → Status: Pending → Approved / Edited / Rejected → Approved Emails Used in Send

7c. Inbound Response Flow

Contact Replies (SMS/Email) → Webhook Received → Auto-Checkout → Status: "Needs BDR"
▼
⚠ BDR Opens Unified Inbox → AI Generates Response Options → ⚠ BDR Selects / Edits → Send Response
▼
Log to Conversation → Check-In (Resume Automation) or HubSpot Lead Handoff

Review Status Lifecycle

Status Meaning Next Actions
Pending AI content generated, awaiting BDR review Approve, Edit, Reject
Approved BDR confirmed content ready to send Queue for delivery
Edited BDR modified AI draft before approval Queue for delivery (edited version)
Rejected BDR declined AI content Re-generate or manual write
