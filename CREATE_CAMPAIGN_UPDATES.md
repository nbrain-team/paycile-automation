# ✅ Create New Campaign Modal - Updated for B2B Lead Generation

## 🎯 Complete Redesign

**Updated from:** Event-based roadshow campaigns  
**Updated to:** B2B lead generation campaigns

---

## ❌ REMOVED (Event-Based Fields)

- Associate Producer → Changed to Campaign Owner
- Event Type (Virtual/In-Person) → Changed to Campaign Type
- City/State (event location) → Changed to Target Persona/Industry
- Event Dates & Times with slots → Simplified to Launch Date
- Hotel Name/Address → Removed
- Locations To Scrape → Removed
- Video Link → Changed to Demo Page Link
- Event Link → Changed to Calendly Link

---

## ✅ ADDED (B2B Lead Gen Fields)

### Core Campaign Info:
1. **Campaign Name** - e.g., "Q1 2025 - CFO Insurance Outreach"
2. **Choose Funnel Template** - Select from 4 Paycile templates
3. **Campaign Owner** - Paycile Team, Sales Team, Marketing Team, BDR Team
4. **Owner Phone** - Contact number

### Targeting:
5. **Campaign Type** - B2B Outreach, Re-engagement, Nurture, Demo Follow-up
6. **Target Persona** - 8 personas (CFO, Controller, AR/AP, etc.)
7. **Target Industry** - Insurance, PropMgmt, Healthcare, etc.

### Campaign Parameters:
8. **Target Company Size** - e.g., "$50M-$500M revenue"
9. **Expected Contacts** - Number field for list size
10. **Launch Date** - When campaign starts

### Links:
11. **Calendly Scheduling Link** - For demo bookings
12. **Demo Page Link** - Landing page URL

## 🎯 Validation Rules

**Required Fields (*):**
- Campaign Name
- Campaign Owner
- Campaign Type
- Target Persona
- Launch Date

**Optional But Recommended:**
- Funnel Template
- Target Industry
- Target Company Size
- Expected Contacts
- Calendly Link
- Demo Page Link

**Submit Button:**
- Disabled until all required fields filled
- Creates campaign in draft status
- Shows success toast notification

Template: CFO Outreach - Insurance Vertical
Owner: Sales Team

Target Persona: CFO / Financial Executive
Target Industry: Insurance
