# INSTRUCTIONS FOR RENDER DEPLOYMENT
# ====================================================================================
#
# 1. CREATE POSTGRESQL DATABASE
#    - Go to Render Dashboard → New → PostgreSQL
#    - Name: your-app-db
#    - Copy "Internal Database URL" to DATABASE_URL above
#
# 2. CREATE BACKEND WEB SERVICE
#    - Go to Render Dashboard → New → Web Service
#    - Connect GitHub repository
#    - Configure:
#      * Name: your-app-server
#      * Root Directory: apps/server
#      * Build Command: pnpm install && pnpm build
#      * Start Command: pnpm start
#    - Add all environment variables from this file
#    - Deploy
#
# 3. CREATE FRONTEND STATIC SITE
#    - Go to Render Dashboard → New → Static Site
#    - Connect GitHub repository
#    - Configure:
#      * Name: your-app-web
#      * Build Command: cd apps/web && pnpm install && pnpm build
#      * Publish Directory: apps/web/dist
#    - Add environment variable:
#      * VITE_API_URL=https://your-app-server.onrender.com
#    - Deploy
#
# 4. UPDATE PUBLIC_BASE_URL
#    - After backend deploys, copy its URL
#    - Update PUBLIC_BASE_URL in backend environment variables
#    - Restart backend service
#
# 5. TEST DEPLOYMENT
#    - Backend health: https://your-app-server.onrender.com/health
#    - Frontend: https://your-app-web.onrender.com
