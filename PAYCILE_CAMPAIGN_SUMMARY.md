## 🔄 Workflow Logic & Decision Trees

Each template uses sophisticated branching:

### Response-Based Branching
- **Positive Response** → Immediate demo scheduling
- **Question/Inquiry** → BDR handoff
- **No Response** → Continue sequence
- **Negative/Unsubscribe** → Exit campaign

### Engagement-Based Scoring
- **High Engagement** (opened 3+ emails, clicked links) → Hot lead to BDR
- **Medium Engagement** (opened 1-2 emails) → Continue nurture
- **Low Engagement** (no opens) → Final push then long nurture

### Channel Performance
- **Email Opened + LinkedIn Accepted** → Priority contact
- **Email Bounced** → SMS + LinkedIn only
- **Email Opened but No Click** → Voicemail drop
- **Video Watched** → Immediate demo offer

### Time-Based Logic
- **Quiet Hours:** 6pm-8am (contact timezone)
- **Daily Caps:** 2 emails, 1 SMS, 1 voicemail max
- **Wait Periods:** 1-7 days between touches
- **Re-Entry:** Single entry (prevent duplicates)
