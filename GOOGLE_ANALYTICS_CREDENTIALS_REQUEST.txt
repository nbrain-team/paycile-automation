Subject: Google Analytics Integration - Credentials Needed

Hi [Client Name],

To integrate Google Analytics tracking with your Paycile platform, we need to set up Google Tag Manager API access. This will allow us to pull analytics data directly into your dashboard for better insights and reporting.

Please follow these steps to create the necessary credentials:

================================================================================
STEP 1: CREATE GOOGLE CLOUD PROJECT (if you don't have one)
================================================================================

1. Go to: https://console.cloud.google.com
2. Sign in with your Google account (the one that has access to your Analytics)
3. Click "Select a project" at the top → "New Project"
4. Name it: "Paycile Analytics Integration"
5. Click "Create"

================================================================================
STEP 2: ENABLE GOOGLE ANALYTICS API
================================================================================

1. In the Google Cloud Console, go to: "APIs & Services" → "Library"
2. Search for: "Google Analytics Data API"
3. Click on it and click "Enable"
4. Also search for and enable: "Google Analytics API" (the older version)

================================================================================
STEP 3: CREATE SERVICE ACCOUNT CREDENTIALS
================================================================================

1. Go to: "APIs & Services" → "Credentials"
2. Click "+ CREATE CREDENTIALS" → "Service Account"
3. Fill in:
   - Service account name: Paycile Analytics Access
   - Service account ID: (auto-generated)
   - Click "Create and Continue"
4. Skip the optional steps by clicking "Continue" → "Done"
5. Click on the newly created service account email
6. Go to the "Keys" tab
7. Click "Add Key" → "Create new key"
8. Select "JSON" format
9. Click "Create" - this will download a JSON file

**IMPORTANT**: Send us this JSON file securely (we'll use it to authenticate)

================================================================================
STEP 4: GRANT ANALYTICS ACCESS TO SERVICE ACCOUNT
================================================================================

1. Go to: https://analytics.google.com
2. Click "Admin" (bottom left)
3. In the "Account" column, click "Account Access Management"
4. Click the "+" button → "Add users"
5. Enter the service account email (from Step 3, looks like: paycile-analytics-access@project-name.iam.gserviceaccount.com)
6. Select "Viewer" role
7. Click "Add"

================================================================================
STEP 5: PROVIDE US WITH THESE DETAILS
================================================================================

Please send us:

1. ✅ The JSON credentials file (from Step 3)
2. ✅ Your Google Analytics Property ID (format: "123456789")
   - Find this in Google Analytics → Admin → Property Settings
3. ✅ Your Google Analytics Measurement ID (format: "G-XXXXXXXXXX")
   - Find this in Google Analytics → Admin → Data Streams → Web → Measurement ID

================================================================================
REDIRECT URIs (if needed for OAuth setup)
================================================================================

If you need to set up OAuth instead of a service account, use these redirect URIs:

https://adtv-events-server-7nfo.onrender.com/api/auth/google/callback

Development (optional):
http://localhost:4000/api/auth/google/callback
